# 一、光盘布局和 ISO 文件系统改动

## 1. 扩大 `PACKDATA.CIG`

原盘 `PACKDATA.CIG` 占 261821 个用户数据扇区。汉化镜像把它扩成 262337 个扇区，多出的 516 个扇区用来放“共用字页 + 运行时代码”的混合块。

目录记录里的 `PACKDATA.CIG` 文件长度被改成新长度。

## 2. 后移原有尾部文件

在原 `PACKDATA.CIG` 结束处插入 516 个扇区后，原来排在它后面的 21558 个扇区整体后移 516 个扇区。

受影响的文件包括：

- `MODHSYN.IRX`
- `LIBSD.IRX`
- `MCMAN.IRX`
- `MCSERV.IRX`
- `ASDMUS.IRX`
- `MODMIDI.IRX`
- `MODMSIN.IRX`
- `PADMAN.IRX`
- `SIO2MAN.IRX`
- `IOPRP234.IMG`
- `SLPM_620.98`
- `SYSTEM.CNF`
- `ZERONOP.DAT`

这些文件的目录记录里的起始位置都后移 516 个扇区。实际内容对比看，除了 `SLPM_620.98` 因为打补丁有内容变化，其他后移文件的内容本身没有改。

## 3. 修改主卷描述符

主卷描述符的卷空间大小被扩大，从原来的 283703 扇区改成 289717 扇区，让追加区域仍在光盘卷空间内。

## 4. 生成新的 CUE

成品还有 `build/image/busin-zh.cue`，指向新的 `busin-zh.bin`。这是新伴随文件，不是原盘 BIN 内部数据。

# 二、插入的 516 扇区混合块

`PACKDATA.CIG` 新增的 516 扇区是一个混合数据块：

1. **保留一份原 chunk 317 的基础数据**
   - 作为新字库块的容器和基础结构。
   - 原位置上的 chunk 317 没有被改掉。

2. **新增共用中文字库页**
   - 当前共用字页有 871 个字符。
   - 开场、旁白等共享这页。

3. **新增运行时代码**
   - 负责按 token 查映射表。
   - 根据当前文本块切换到对应的分块字库页。
   - 处理字符编号超过原字库上限的情况。

4. **修改资源表**
   - 原程序里的正文 font 资源表和开场 font 资源表都改成指向这个新增混合块。
   - 也就是说，程序不再按原盘旧字库块读取，而是读这块扩容后的数据。

# 五、`SLPM_620.98` 程序改动

程序文件本身随光盘尾部后移，然后在新位置上打了补丁。实际有 116 个旧扇区的内容发生变化。

补丁片段统计：

| 用途 | 补丁片段数 | 写入字节数 |
|---|---:|---:|
| 台词分页字库 hook 和代码洞 | 30 处 | 324 字节 |
| 界面分页字库代码 | 38 处 | 540 字节 |
| 界面文本和排版数据 | 2363 处 | 78082 字节 |
| 合计 | 2431 处 | 78946 字节 |

主要分几类。

## 1. ELF 文件大小调整

程序头里的文件大小被扩大，把原本靠近末尾、可安全使用的空隙纳入文件范围，用来放补丁代码。

## 2. 台词字库分页机制

修改了原来的字体读取、提交和完成路径：

- 拦截原来的字库页提交点
- 按当前文本块切换专用字库槽
- 用 token 映射表把中文字符编号映射到当前页格子
- 开场字库和正文字库都接到新机制
- 保留原共用字页的路径，避免所有场景都强制走新页

## 3. 界面字库分页机制

修改了界面字库加载和绘制：

- 把原来展开的 chunk 0 解析代码替换成更紧凑的解析器
- 原有四张界面字库页仍照常解析
- 启动过程中异步读取追加的六张中文字库页
- 字库页上限从 4 页改成 10 页
- 多处绘制点改成通过统一 helper 取实际字库页句柄

## 4. 界面文本直接写入 ELF

当前 28 组界面文本全部有译文：

- 界面字符串：2632 条
- 隐式跳过：0 条
- 保留日文：0 条
- 新界面字形：1400 个

覆盖的范围包括菜单、商店、存档、创建角色、职业、种族、能力、怪物、地名、人名、委托、旅馆、调试界面等。

## 5. 界面排版微调

为了让三格中文占位和原来的日文占位对齐，还改了一些固定坐标和间距逻辑：

- 羊皮纸文本行距加宽
- 种族列表改用统一起始横坐标
- 状态表短名称改用三字宽起始横坐标
- 创角属性名改用统一起始横坐标
- 分配点数属性名改用统一起始横坐标
